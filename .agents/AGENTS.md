# Repository guidelines

## Code

- Do not add tests.
- Keep every line added or changed by the agent in its diff at or below 120 characters.
- Write small functions, each with one clear responsibility.
- Separate logical blocks of code with blank lines.

## README

- Treat the README as public project documentation for users.
- Describe only the project's current state.
- Do not include change history, migration instructions, or explanations of compatibility with earlier versions.
- Avoid deep implementation details; a high-level architecture overview is welcome.
- Do not include personal instructions or explanations addressed to the repository owner.
